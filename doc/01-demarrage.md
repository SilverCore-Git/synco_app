# 1. Bien débuter avec Synco

## Connexion à votre compte

Synco utilise un système d'authentification unique (SSO) hautement sécurisé géré par Keycloak. 
1. Rendez-vous sur la page d'accueil de l'application.
2. Vous serez redirigé vers le portail de connexion sécurisé.
3. Entrez vos identifiants professionnels pour accéder à votre espace de travail.

## Rejoindre une organisation

Si vous avez reçu un **lien d'invitation** :
1. Cliquez sur le lien (au format `.../invite/CODE`).
2. Connectez-vous si ce n'est pas déjà fait.
3. Vous serez automatiquement ajouté à la liste des membres de cette organisation.

## Sélectionner son organisation

Une fois connecté, vous arriverez sur la page **Sélection de l'Organisation**.
- Cliquez sur l'organisation avec laquelle vous souhaitez travailler.
- Vous serez dirigé vers l'accueil de cet espace, où vous retrouverez l'ensemble de vos notifications et raccourcis.
- Si vous faites partie de plusieurs organisations, vous pourrez basculer de l'une à l'autre via le menu dédié sur l'interface principale.
