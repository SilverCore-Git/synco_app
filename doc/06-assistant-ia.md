# 6. Assistant IA et Recherche Sémantique

Synco vous offre une intelligence artificielle d'assistance, axée sur la souveraineté des données. Pour préserver votre confidentialité absolue, le traitement s'effectue localement selon le modèle configuré.

## Recherche Sémantique

Plutôt que de rechercher par de simples mots-clés basiques, Synco vous permet de formuler vos requêtes en langage naturel.
- Grâce au système de vectorisation sémantique local, les textes de vos fichiers (comme les PDF que vous uploadez) sont indexés intelligemment.
- L'IA "comprend" le sens et le contexte de vos documents. Vous pouvez ainsi lui poser une question précise et elle retrouvera le paragraphe le plus pertinent caché dans les ressources de votre organisation.

## Modèles Locaux (Edge AI)

Pour des raisons de confidentialité, le module d'intelligence artificielle (`OrgAI`) permet d'exécuter des modèles de langage open-source européens directement dans votre environnement, sans qu'aucune de vos requêtes ne soit envoyée à une entreprise tierce ou sur le Cloud public.
- Cela garantit une conformité stricte et aucune fuite de données privées (privacy-first).
- L'assistant est capable de répondre à vos questions sur les documents, de les résumer, ou d'activer des outils de manière autonome pour vous assister au quotidien.
